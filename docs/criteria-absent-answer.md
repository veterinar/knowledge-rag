**Вывод замера.** `raw_score` — это RRF, счёт по рангам, а не по релевантности: он принимает одни и
те же значения (0,01176 при bm25_rank=1 без семантики; 0,00558 при semantic_rank=1 без BM25) для
настоящего попадания и для совпадения по одному общему слову. Порог по `raw_score` отделить «есть» от
«нет» **не может**: два настоящих попадания (ASVCP, гипостенурия) дали те же 0,012/0,0118, что шесть
ложных. Правило «оба источника ранга есть → присутствует» верно на 6 из 8 «есть» и на 0 из 8 «нет», но
даёт ложное «отсутствует» на 2 из 8 настоящих. Значит, ответ «отсутствует» требует **абсолютного**
сигнала релевантности, которого в ответе сейчас нет: сырого счёта BM25 (с IDF — совпадение по «завтра»
дёшево, по «Thrall» дорого) и косинусной близости семантического попадания. Кросс-энкодер в конфиге
выключен (`reranker_model: disabled`).

## Задача одной фразой

`search_knowledge` возвращает поле `absent` с основанием, когда ни лексический, ни семантический
сигнал не достигает калиброванного абсолютного порога, и продолжает возвращать результаты как есть в
остальных случаях; пороги берутся из калибровочного набора, не назначаются.

## Критерии приёмки

- **AC-A1 — абсолютные счёты в ответе.** Каждый результат несёт `bm25_score` (сырой BM25 попадания или
  `null`) и `semantic_similarity` (косинус или `null`) рядом с существующими `raw_score`,
  `query_relative_score`, `score_source`; существующие поля и имена инструментов не меняются
  (контракт `acceptance-scoring-contract.md`).
- **AC-A2 — калибровочный набор в репозитории.** Файл `bench/absent-calibration.v1.yaml` с ≥ 10
  заведомо-присутствующими и ≥ 10 заведомо-отсутствующими запросами для корпуса поколения (запросы
  «есть» ссылаются на конкретный документ; «нет» — вне предмета корпуса) и результатами замера
  `bm25_score`/`semantic_similarity` на названном поколении (generation_id, receipt_sha256).
- **AC-A3 — порог из замера.** Пороги `absent.bm25_floor` и `absent.semantic_floor` записываются в
  конфиг **вместе с идентичностью замера**; значение — из калибровочного набора (например, максимум
  «нет» и минимум «есть» с зазором, если они разделимы; если не разделимы — это записывается как
  результат, и `absent` не включается). Число без замера в конфиг не попадает.
- **AC-A4 — правило и его форма.** Ответ несёт объект `absent: {verdict: true|false|undetermined,
  basis: "...", bm25_max: x, semantic_max: y}`; `true` только когда оба сигнала ниже полов;
  `undetermined` — когда порог не откалиброван для текущего поколения. Результаты при `absent: true`
  всё равно возвращаются (читатель видит, на что было похоже).
- **AC-A5 — контракт счётов не нарушен.** `min_score` по-прежнему фильтрует `query_relative_score`;
  документация не называет универсальных порогов; `absent` описан как калиброванный на поколение.
- **AC-A6 — RED/GREEN.** На неисправленной базе проба «канарейка вне предмета → absent.verdict=true»
  красная; на кандидате зелёная; проба «настоящий запрос по одному слову (ASVCP, гипостенурия) →
  absent.verdict=false» зелёная на кандидате (защита от ложного «нет»).
- **AC-A7 — смена поколения обнуляет калибровку.** Если generation_id/receipt не совпадает с
  идентичностью замера в конфиге, `absent.verdict=undetermined` с основанием — не наследуется порог
  чужого корпуса.

## RED — мутации

| мутация | что обязано покраснеть |
|---|---|
| поднять `bm25_floor` выше настоящего попадания по одному слову | AC-A6 (ложное «нет») |
| убрать `semantic_similarity` из ответа | AC-A1 |
| подменить generation_id в конфиге калибровки | AC-A7 → `undetermined` |
| убрать один запрос «нет» из набора (< 10) | AC-A2 — валидатор набора |

## Не-цели

- Смена ранжирования, RRF, реранкера, эмбеддингов, чанкинга (контракт scoring).
- Включение кросс-энкодера как источника абсолютного счёта — отдельное решение (стоимость запроса).
- Универсальный порог для всех поколений и корпусов.

## Остаточный риск

Калибровочный набор из 20 запросов задаёт пол, а не гарантию: запрос «нет» с редким словом, совпавшим
с редким словом корпуса, пройдёт BM25-пол. Поэтому `absent` — подсказка читателю с основанием, не
оракул; читатель по-прежнему смотрит `basis`.
