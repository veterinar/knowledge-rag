# Критерии: SAFE_COMPONENT — якорь \Z вместо $ (hardening)

SDD: class LOW, mode bugfix. Находка проверочной кампании 28.08 (замер:
`re.compile(r"^[A-Za-z0-9][A-Za-z0-9._-]*$")` матчит `"x\n"` — в Python
`$` совпадает перед финальным \n; traversal невозможен — `/` и `..`
режутся, — но имя файла с хвостовым переводом строки прошло бы в out).
Fail-closed требует `\Z`.

## Критерий 1

В `scripts/build_notion_corpus.py` строка 52: паттерн `SAFE_COMPONENT`
меняет только якорь конца — `...._-]*$")` → `...._-]*\Z")`. Ничего
другого в файле не меняется.

**Проверка**: `SAFE_COMPONENT.match("x\n")` возвращает None на кандидате
(на базе b7f0636 — матч, RED).

## Критерий 2

В `tests/test_build_notion_corpus.py` добавляется один параметр-кейс к
существующему unsafe-тесту (рядом с `"../../evil-record"`, тот же
образец): запись с `id` = `"trailing\n"` → build отказывает кодом 2, файл
с таким именем не создаётся, out не создан.

**Проверка**: pytest кейса зелен на кандидате; на базе b7f0636 тот же
кейс красный (RED — файл создаётся, exit 0).

## Не-цели

Прочие паттерны, поведение, сообщения и CHANGELOG-стиль моста не
меняются (CHANGELOG-bullet добавит контролёр отдельно).
